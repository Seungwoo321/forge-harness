# 관리 workspace의 직접 종료

## 문맥

마지막 surface를 임시 대체 surface로 바꿔 닫으면 관리 workspace에 유휴 셸이 남을 수 있다. surface가 사라진 것만으로는 workspace 정리를 증명하지 못하고, native 목록은 성공한 종료 명령보다 늦게 갱신될 수 있다.

## 결정

세션 어댑터는 전용 관리 workspace를 지원되는 workspace 종료 명령으로 직접 닫고 대체 surface를 만들지 않는다. 변경 전에 모든 surface 유형의 완전한 목록과 정확한 소유자·worker·수신자·경로를 확인한다. 공유·외부 workspace에는 정확한 소유자 surface 종료만 사용한다.

효과 원장은 변경 전에 선택한 workspace 또는 surface 대상을 원 close 인자에 결속해 저장한다. 정합화는 이미 시도한 명령을 반복하지 않고 같은 대상을 관찰한다. 완료는 선택한 대상이 완전한 목록에서 사라져야 성립한다. 영속 대상 증거 없이 소유자만 사라지고 관리 workspace가 남으면 미검증이다.

## 결과

지연된 목록은 기존 관찰 한도 안에서 재관찰한다. 응답 유실은 원 intent와 대상을 유지한다. 지원되지 않거나 모호한 목록, 바뀐 신원·경로는 닫힌 쪽으로 실패한다. 호스트에는 원자적 목록 비교·종료 트랜잭션이 없으므로, 마지막 새 목록과 신원 확인이 지원되는 명령 직전의 fence다.
