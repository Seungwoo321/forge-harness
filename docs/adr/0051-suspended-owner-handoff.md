# 0051 — Explicit handoff from a suspended existing owner

A live native session may be unable to continue while the user explicitly authorizes another provider to complete its original unit. Restart recovery requires the same native thread and absence of the old process. Closing the original session would destroy the requested preserved context.

A separate public `unit session-handoff` transition preserves the Unit Record and every original custody receipt. It verifies the current goal, source, target, ledger, actual user authorization, next execution policy and both native identities. The host suspends the exact previous process and its descendants outside the read-only verifier. Native observation proves every process remains stopped before and after observing the replacement. An append-only goal handover and its next execution policy commit atomically.

Adoption and restart contracts remain unchanged. Missing authority, ambiguous identities, running descendants, unsettled reviewers and uncertain effects reject handoff without effects. The new session retains existing ownership and cannot automatically close either user session. Resuming the old process requires separate operator action; it does not restore its superseded custody.

An unregistered reviewer that has done native work cannot truthfully use terminal non-start recovery. An explicit suspended reviewer inventory binds its original unresolved startup, exact native identity, complete unit/ledger/target/source and immutable original policy. Its ledger and unit remain unchanged at handoff. A separate source-verified recovery callback proves continued suspension without asserting taskNeverStarted and reserves the same review unit at its next attempt. Registered reviewers or opened/submitted review stages remain outside this path.

Reviewer ledger acquisition is nonblocking while holding the target, then reviewer unit locks precede the goal lock. This avoids waiting in reverse against startup. The handoff commits no running/pending/unknown effect. Canonical native identity excludes transient observation metadata. Original review-role account overrides are read from the original snapshot. Competing transfers, mismatched receiver/confirmation identities, running children and changed snapshots reject before commit.

A source owner may independently exit before the authorized transfer. That observation does not imply an authorized close, and cannot satisfy suspension. A distinct `unit session-reassign` route uses separate effect authorization and an exited-owner verifier. It binds preserved original native/custody authority, current target and replacement, and repeatedly proves the original exact surface/PID absent around native caller observation. The host verifies exclusive continuation from actual historical/current native evidence. Its `exited-owner` audit is distinct from suspended-owner handoff and cannot share a replay identity. No close action or non-start evidence is fabricated. A still-live original reviewer continues through the separately proved suspended-review contract.
