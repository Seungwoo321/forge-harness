# 전달 후 재작업과 기존 종료 권한

전달이 끝난 뒤 새 사용자 지시로 같은 단위의 수용 기준이 수정되면 이미 적용된 전달과 영수증은 감사 이력으로 보존한다. 새 기준의 구현은 기존 수용·리뷰·게이트를 무효화하고 별도 시도로 다시 수용한다.

전달 후 재작업은 이전 결과 전달이나 소유자 종료가 불확실한 동안 진행하지 않는다. 신뢰 제공자는 이전 finalizer가 더 이상 실행되지 않고 기존 결과 메시지와 소유자 종료가 확정적으로 정리됐음을 실제 native 관찰로 입증한다. 이전 프로세스가 구 코드로 계속 실행 중이면 새 코드의 검사만으로 안전성을 보장할 수 없다.

수용된 목표가 변경된 뒤 오래된 finalizer는 원 소유자를 종료하지 않는다. 종료 효과 전 단위 잠금과 목표 잠금 아래 현재 finalization, 목표 revision 및 수용 기준을 재검사하고 목표 완료 예약을 영속화한다. 예약은 소유자 종료와 단위·목표 완료 기록이 끝날 때까지 다른 목표 전이를 차단한다.

재작업 요청은 사용자 원문, 현재 단위·목표 revision, 이미 전달된 tree·효과와 최종화 계획에 결속한다. 목표에 동일 요청의 재작업 예약을 먼저 기록해 원장 기록과 단위 갱신 사이의 중단에서도 다른 목표 전이가 끼어들지 않게 한다. 재호출은 같은 영수증을 반환하고, 다른 내용·현재 대상의 변경·불확실한 외부 효과는 거부한다. 이전 accepted·delivery·finalization·수용 기준과 증거는 변경 전 원본을 보관하며 새 증거로 대체하지 않는다.
